# AI-Assisted Technical Services

Practical help with technical documentation, software troubleshooting, research organization, and clearly scoped development tasks.

## Services

- Technical reports and structured Markdown documentation
- Calculation, test, and verification documentation
- Software troubleshooting and bug reproduction
- Website fixes and small feature improvements
- Workflow analysis and automation assistance
- AI-assisted workflow design and integration support

## Working approach

Each engagement starts with an agreed task, scope, expected deliverable, and timeline. Findings are documented honestly. Assumptions, unresolved questions, and limitations are identified rather than presented as verified results.

AI tools may support the workflow, but generated output is not treated as verified evidence without appropriate checks.

## Project scope

Small, well-defined tasks and larger milestone-based projects are both welcome. Scope, access requirements, delivery terms, and pricing should be agreed before work begins.
